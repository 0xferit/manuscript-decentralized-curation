# RPGF

Retroactive public goods funding (RPGF) is a public-goods application of the decentralized curation framework.

The [public-goods companion paper](companion-paper/manuscript.md) is the current working source for the application. It develops ongoing assessment and funding, with evidence records and a checked example. Its [website edition](https://manuscript-decentralized-curation.pages.dev/rpgf/companion/) is a working revision; the deposited preprint and its verification records remain historical snapshots.

The companion supersedes the [earlier fixed-round design](design.md), which is retained as historical material. Its rules are not an alternative current specification.

Edit current application prose in `companion-paper/manuscript.md`; the foundational `paper.qmd` at the repository root owns shared protocol rules. Preserve historical source excerpts, digests and publication records when revising the working paper.

Thin root-level Quarto wrappers publish the overview at `/rpgf/` and the companion at `/rpgf/companion/`. The legacy `/rpgf/design/` route remains available as a clearly marked archive, outside the active document tree and search index.
