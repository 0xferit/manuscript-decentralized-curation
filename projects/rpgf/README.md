# RPGF

RPGF is the retroactive public goods funding instantiation of the decentralized curation framework.

- `design.md`: canonical RPGF mechanism-design document

Relation to the thesis:
- The thesis frames RPGF as one downstream application of the broader curation methodology.
- This directory holds the standalone project design document rather than keeping it as a root-level side file.

Source-of-truth policy:
- Edit RPGF content in this directory.
- `design.md` remains the canonical RPGF paper source.
- Published routes are served via `/rpgf/` and `/rpgf/design/` through thin root-level Quarto wrappers.
