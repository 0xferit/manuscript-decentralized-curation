# Projects

This repo is organized paper-first. The thesis remains at the root, while project-specific spinout documents live here.

- [Truth Post](truth-post/README.md): proposed news blueprint and historical partial-deployment report.
- [Public goods funding](rpgf/README.md): ongoing-funding companion paper and a distinct batch reference proposal.

Canonical project content is edited under `projects/`, while published routes are served through thin root-level Quarto wrappers:

- `/truth-post/` and `/truth-post/blueprint/`
- `/rpgf/` and `/rpgf/design/` for the batch reference proposal; the ongoing companion has a separate document build and publication record

Shared diagrams, simulations, and bibliography remain in the thesis layer at the repository root.
