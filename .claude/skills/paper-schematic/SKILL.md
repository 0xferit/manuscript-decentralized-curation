# paper-schematic: conceptual diagrams for the decentralized-curation manuscript

## When to use
Trigger when the user asks to add, create, draw, illustrate, or generate a **conceptual** diagram: a schematic, flow diagram, state machine, protocol architecture, or actor-interaction diagram. Do **not** trigger for simulation output figures: those come from `analysis/run_all.py`.

## Delegate methodology to
`claude-scientific-writer:scientific-schematics` for diagram design, AI-assisted generation, and quality review.

## Project file conventions
- **Conceptual figures** live at `diagrams/fig-*.png`, generated by `diagrams/generate_diagrams.py` (matplotlib). Run directly with `python3 diagrams/generate_diagrams.py`.
- **Simulation figures** live at `analysis/fig/` and are regenerated by `analysis/run_all.py`. That directory is gitignored; never commit into it by hand.
- New conceptual figures should be **added to `diagrams/generate_diagrams.py` as a named generator function**, not dropped as standalone PNGs, so generation stays deterministic and reproducible.

## Figure quality checklist
- Labeled axes, legible fonts, vector format where possible.
- No misleading visual encodings (skewed aspect ratios, truncated axes without note).
- Colorblind-safe palette.
- Embedded in `paper.qmd` via a Quarto fenced chunk or relative image reference so `quarto render` picks it up.

## Output shape
Either (a) a patch to `diagrams/generate_diagrams.py` that adds a generator function for the new figure, plus the updated `paper.qmd` reference; or (b) a standalone AI-generated schematic written to `diagrams/fig-<slug>.png` with a note that the user should later convert it to a matplotlib generator for reproducibility.
